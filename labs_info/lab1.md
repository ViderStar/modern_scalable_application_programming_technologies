## Задание

Учебная подсистема ввода и модификации данных о клиентах условного банка. Java + Spring,
реляционная база в памяти (H2), заполняется при старте.

1. Выбрать поля клиента по номеру варианта.
2. Схема данных со справочниками для полей типа «Список», реализовать в СУБД.
3. Формы: добавление, удаление и редактирование клиента; «Список клиентов» с сортировкой
   по фамилии.
4. Микросервис для REST-подключения к базе, web-клиент на любом JS-фреймворке.
5. Проверка каждого поля — **дважды: на клиенте и в REST**.
6. Не менее 5 клиентов в базе, включая себя.
7. Тесты на WebDriver по пунктам защиты.

## Как устроено

- **Схема** — `schema.sql`: таблица `client` и справочники `city`, `marital_status`,
  `citizenship`, `disability`. Уникальность паспорта и идентификационного номера закреплена
  ограничениями в базе. Данные — `data.sql`.
- **REST** — `ClientController`: `GET/POST /api/clients`, `GET/PUT/DELETE /api/clients/{id}`,
  `GET /api/dictionaries`. Ошибка всегда в виде `{message, fields: {поле: сообщение}}`.
- **Проверка на клиенте** — `static/app.js`: описание полей `SECTIONS` (обязательность,
  маска, `check`) и функция `validate`.
- **Проверка в сервисе** — `ClientRequest` (`@NotBlank`, `@Pattern`, `@DateText`) и маски
  в `Masks`; уникальность — `ClientService.checkUnique`.
- **Даты** — текстом `ДД.ММ.ГГГГ`, разбор в режиме `STRICT`: 31.02.2015 и 29.02.2015 отвергаются.

## Программа защиты

| № | Действие | Что должно быть | Автотест `ClientUiIT` |
|---|---|---|---|
| 1 | Ввести себя ещё раз | ошибка, в базе один клиент | `sameClientTwice` |
| 2 | Другой клиент, тот же паспорт | ошибка | `anotherClientWithSamePassport` |
| 3 | Другой клиент, тот же идент. номер | ошибка | `anotherClientWithSameIdentificationNumber` |
| 4 | Фамилия `1234` | ошибка, в базе нет | `digitsInsteadOfLastName` |
| 5 | Пробел вместо имени | ошибка | `spaceInsteadOfFirstName` |
| 6 | Не дата / 31.02.2015 / 29.02.2015, поля с маской | ошибка | `birthDateIsNotDate`, `maskedFields` |
| 7 | Нет одного обязательного поля | ошибка, записи нет | `requiredFieldIsMissing` |
| 8 | Только обязательные поля | клиент записан | `onlyRequiredFields` |
| 9 | Показать двойную проверку | два фрагмента кода | `app.js` и `ClientRequest` — выделены в отчёте |

Проверка «прямо в базе»: `http://localhost:8081/h2-console`, JDBC URL `jdbc:h2:mem:clients`,
пользователь `sa`, пароль пустой, затем `SELECT * FROM CLIENT`.
