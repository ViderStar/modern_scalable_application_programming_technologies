## Задание

1. Для банка своего варианта выбрать отзывный вклад до востребования с ежемесячной выплатой
   процентов и срочный безотзывный вклад с выплатой процентов в конце срока.
2. Справочник «План счетов» со счетами для этих депозитных линий.
3. Форма договора: вид депозита и валюта из справочников, номер, даты, срок, сумма, процент;
   контроль корректности.
4. Клиент — из модуля «Клиенты». При заключении договора — минимум два счёта (основная
   сумма и проценты): 13-значный номер, код и активность из плана счетов, дебет, кредит,
   сальдо, название — ФИО клиента.
5. Счёт фонда развития банка (СФРБ) со стартовым капиталом 1 млн BYN.
6. Процедура «Закрытие банковского дня» и отчёт по счетам (при активных программах —
   минимум 6 счетов).

## Счета и проводки

Номер счёта: `ББББ` (балансовый счёт) + `ККККК` (код клиента) + `ННН` (номер счёта клиента)
+ ключ. Ключ = (3 · Σ dᵢ·wᵢ) mod 10, веса 7, 1, 3 по кругу.

Сальдо: активный счёт — дебет − кредит, пассивный — кредит − дебет.

| № | Операция | Касса 1010 (А) | СФРБ 7327 (П) | Вклад (П) | Проценты (П) | Когда |
|---|---|---|---|---|---|---|
| 1 | Внесение денег в кассу | Дт + | | | | договор |
| 2 | Перевод с кассы на текущий счёт | Кт − | | Кт + | | договор |
| 3 | Использование денег банком | | Кт + | Дт − | | договор |
| 4 | Начисление процентов | | Дт − | | Кт + | каждый день |
| 5 | Перевод процентов в кассу | Дт + | | | Дт − | выплата |
| 6 | Вывод процентов из кассы | Кт − | | | | выплата |
| 7 | Окончание депозита | | Дт − | Кт + | | конец срока |
| 8 | Перевод депозита в кассу | Дт + | | Дт − | | конец срока |
| 9 | Вывод денег из кассы | Кт − | | | | конец срока |

Проценты: `I(t) = round(S · r · дни / 36500, 2)` — накопленная сумма; в проводку идёт разность
с уже начисленным.

## Как устроено

- **account-service** — главная книга. `LedgerService.post` проводит пакет операций в одной
  транзакции, с блокировкой счетов и проверкой остатка; ключ пакета делает повтор безопасным.
  `BankDayService.close` оповещает участников и сдвигает дату после их ответа.
- **deposit-service** — `DepositService.open` (проверки, два счёта, проводки 1–3),
  `processDay` (начисление, выплата, закрытие), `DepositPostings` — проводки как в таблице.
- **bank-common** — `LedgerApi`, `ClientApi` (`@HttpExchange`), `ApiError`.

## Сценарий демонстрации

1. Запустить с капиталом 1 млн: `BANK_FUND_CAPITAL_BYN=1000000 scripts/run-all.sh`.
2. «Депозиты» → заключить два договора по разным программам.
3. «Счета» → в отчёте 6 счетов; закрыть 31 день → по отзывному вкладу проценты выплачены,
   по срочному копятся на счёте 3471.
4. Закрыть дни до даты окончания → вклады возвращены, сальдо клиентских счетов и кассы
   нулевое, фонд = капитал − выплаченные проценты.

```bash
./mvnw -pl account-service,deposit-service -am verify
```
